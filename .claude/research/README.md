# Research (archive)

This directory is an archive of the tool studies (loora, dim0, tailwindeditor) done before the
specs existed. It records what was true when each was written and is not re-surfaced or cited as
authority. `.claude/specs/` is the source of truth; anything these studies fed into a decision has
already been absorbed into the specs.

**One exception, marked live in its own header:** `agent-subscriptions-and-acp.md` is open research
feeding a decision nobody has made yet — how the app drives Claude Code / Codex / Cursor / OpenCode
on the developer's own subscription. Append to it; it retires into the archive once the
decision lands in a spec.
