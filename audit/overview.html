QYour specific questions, answered

evals/ — what is it? delete candidate

A CLI-only LLM-as-judge eval harness for the discovery prompt (6 files). Not a route, not a panel. Zero imports from app/server code, and the documented bun run eval:discovery can't even run — package.json has no scripts field. Keep only if you plan to measure discovery-prompt changes; otherwise delete the folder.

prompts/ — what is it? keep

Not a UI prompt library — it's the prompt-builder functions behind every AI feature. All 16 modules are imported (registry, chat submit, create-page, html/jsx pipelines, discovery route). Deleting anything here breaks generation. Individual files only die if you cut their parent feature.

docs/ — does code derive from it? prune, one caveat

No code reads or imports docs/ at runtime. The only coupling: 5 generation prompts contain the literal string "Read the generation guide: docs/iterations/guide.mdc" — the spawned agent reads that file, so deleting it degrades generation quality without breaking code. Everything else (PROJECT-OVERVIEW, AGENT-DESIGN-FRAMEWORK, ui/, conventions/, canvas/, generation/) is referenced by nothing.

dev-store — why does it exist? decide

stores/dev-mode-store.ts: one persisted boolean. Reached by a hidden gesture — right-click the "Model settings" sliders button in the header (PlaygroundHeader.tsx:228-242) → "Dev mode" toggle → reveals extra header buttons (e.g. the Eraser "Clear all", :259-264). Sole consumer is the header. Removal surface: the store, header wiring, DEV_MODE_STORAGE_KEY (lib/constants.ts:95).

Highlight tool remnants 3 leftovers

The highlighter pen itself is gone (DrawPenKind = 'pen' only). Left behind: a dead CSS block playground-global.css:413-423 ([data-draw-kind="highlight"] can never match), a stale comment at :397, and a done-already TODO at README.md:201. Note: ElementHighlight.tsx is unrelated — it's the live alt+click element-selection overlay. Keep it.

"use client" removal — complete? 11 missed

11 files still carry the directive: BrowseShell, PlaygroundCanvasDrawLayer, lib/canvas-flow.tsx, and 8 components/ui/* shadcn primitives (accordion, alert-dialog, dialog, dropdown-menu, inline-reference ×2, sonner, tooltip). Plus stale comments in lib/jsx-utils.ts:24-45 claiming the directive is still prepended, and a prompt at lib/jsx-prompts.ts:58 telling the model to keep it.
